# Partha Sarathi Mohanta

[Live portfolio](https://parthaxd.github.io/Hz/). The site is plain HTML and CSS.

## Add a photograph

On the **gh-pages** branch, upload the image into **photos/**. Open **photography.html** and copy the figure inside the PHOTO TEMPLATE comment. Paste it inside the gallery, or replace an existing figure. Replace the filename in both places, write a description for the image, and add your caption. Keep the original aspect ratio. Portraits, panoramas and squares flow into the same gallery. Commit the change to publish it.

## Add a past event

On **gh-pages**, open **events.html**. Copy the EVENT TEMPLATE article into the entries section. Fill in the date, venue, event name and your role. Put the newest entry first. For a photo, upload a file to photos/ and insert the template’s img inside the event-photo box. It uses a centred square crop.

## Other edits

Edit **projects.html** for projects or **cv.html** for the printable CV. GitHub Pages serves **gh-pages**. If editing on **main**, merge those changes into **gh-pages** to publish. After editing directly on **gh-pages**, merge it back into **main** to keep both branches in sync.
