# Partha Sarathi Mohanta

[Live portfolio](https://parthaxd.github.io/Hz/). The site is plain HTML and CSS.

## Add a photograph

On the **gh-pages** branch, upload the image into **photos/**. Open **photography.html** and copy the figure inside the PHOTO TEMPLATE comment. Paste it inside the gallery section, outside the comment. Replace the filename in both places, write a description for the image, and add your caption. Commit the change to publish it.

## Add a past event

On **gh-pages**, open **events.html**. Copy the article inside the EVENT TEMPLATE comment into the entries section. Fill in the date, venue, event name and your role. Put the newest entry first. The empty-state message disappears when the first article is present.

## Other edits

Edit **projects.html** for projects or **cv.html** for the printable CV. GitHub Pages serves **gh-pages**. If editing on **main**, merge those changes into **gh-pages** to publish. After editing directly on **gh-pages**, merge it back into **main** to keep both branches in sync.
